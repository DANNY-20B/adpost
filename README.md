# AdPost

A responsive, dependency-free Nigeria-focused marketplace prototype. Open `index.html` directly in a modern browser; no install or build step is required.

## Included

- Home page with featured listings, six category shortcuts and working search.
- Ad browsing with text search, category, city, condition and naira-price filters.
- Advertisement details with photo thumbnails, telephone and WhatsApp links.
- Create, edit and delete advertisements, including multiple resized photo uploads.
- Saved ads and a local listings dashboard.
- Responsive mobile navigation and layouts.

Advertisements created in the browser and saved ads persist in that browser's local storage. Sample ads are included so browsing works immediately.

## Prototype boundaries

This is a static, browser-only prototype: saved listings are local to one browser and do not sync with other visitors. User registration/password authentication, server-hosted image uploads, genuine moderation/admin controls, reporting, and paid featured placements require a backend and are not implemented here. Do not enter real account passwords. Featured sample placements are illustrative. Sample photographs load from Unsplash and therefore require an internet connection.
